# TechHub Login Page

> **Practice Demo:** This is a frontend-only login page. Authentication is simulated locally. No real login, backend, or database is connected.

## Overview

TechHub Login Page is a modern, responsive login interface built as a frontend practice project using HTML, CSS, and vanilla JavaScript.

## Features

- Responsive dark navy and indigo design
- Email and password input fields
- Show/hide password toggle
- Client-side email and password validation
- Accessible validation and feedback messages
- Loading state during simulated form submission
- No external libraries or dependencies

## Tech Stack

- **HTML5** — page structure and form
- **CSS3** — styling, responsive layout, and animations
- **Vanilla JavaScript** — validation and user interactions

## Project Files

| File | Purpose |
|---|---|
| `index.html` | Login page structure |
| `style.css` | Visual design and responsive styles |
| `script.js` | Form validation and demo interactions |

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/rohangadge-dev/techhub-login-page.git
   ```

2. Open the project folder.
3. Open `index.html` in a modern web browser.

No build step or package installation is required.

## Demo Behavior

- Email is required and checked for a basic valid format.
- Password is required and must contain at least 8 characters.
- Submitting valid inputs triggers a simulated loading and success flow.
- The form does not authenticate a real user.

## Limitations and Security

- This project has no backend, authentication service, or database.
- Do not enter real passwords or sensitive information.
- Credentials are not intended to be stored or sent to a server.
- Client-side validation is for user experience only and is not sufficient for production authentication.
- The “Forgot password” and sign-up links are placeholders if not connected to real pages.
- A production login system would require secure server-side authentication, HTTPS, and appropriate session management.
